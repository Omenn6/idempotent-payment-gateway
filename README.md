# Idempotent Payment Gateway

Асинхронный сервис проведения платёжных операций через внешний симулятор провайдера.

## О проекте

Проект представляет собой легковесное и устойчивое решение, сфокусированное на надёжности обработки транзакций. Сервис спроектирован так, что сохраняет корректное состояние и гарантирует целостность данных в следующих сценариях:
- **Повторные запросы** (при многократной отправке одной и той же операции со стороны клиента).
- **Конкурентные запросы** (при одновременных попытках обработки транзакции из разных потоков).
- **Потерянные HTTP-ответы** (в случае сетевых сбоев при обмене данными с внешним провайдером).
- **Внезапные перезапуски контейнеров** (в случае аварийной остановки или перезагрузки сервиса в процессе обработки).

> **Примечание:** В соответствии с требованиями ТЗ, в проекте намеренно отсутствует избыточная «большая» архитектура. Фокус полностью смещён на создание стабильного, воспроизводимого и устойчивого сквозного сценария.

## Инструкция по запуску


### Запуск через Docker Compose

Для автоматической сборки и запуска инфраструктуры выполните следующие шаги:

1. **Соберите и запустите проект**  
   В терминале в корне проекта введите команду, которая автоматически соберет Docker-образы, применит миграции базы данных и поднимет все сервисы:
   ```bash
   docker compose up --build
   ```

2. **Доступные ссылки для взаимодействия с проектом**  
   Взаимодействие с системой возможно по следующим адресам:
   - **Основной сервис (FastAPI)**: http://localhost:8080  
   Интерактивная документация (Swagger): http://localhost:8080/docs
   - **Симулятор провайдера**: http://localhost:8081

## Автоматическое тестирование


Для запуска встроенных интеграционных тестов выполните команду в корне проекта:

```bash
pytest
```

Тесты комплексно проверяют механизмы идемпотентности, обработку конкурентных запросов, восстановление задач при перезапуске, логику повторных попыток и историю изменений транзакций.

## Сквозной сценарий проверки


Вы можете пошагово проверить работу платёжного шлюза вручную с помощью утилиты `curl`. Выполняйте команды последовательно в соседнем окне терминала:

### 1. Проверка готовности

```bash
curl -i http://localhost:8080/health
```

### 2. Создание операции

```bash
curl -i -X POST http://localhost:8080/operations \
  -H "Content-Type: application/json" \
  -d '{
    "operationId": "test-operation-1",
    "amount": "100.00",
    "currency": "RUB",
    "description": "test-1"
  }'
```

### 3. Проверка идемпотентности

```bash
curl -i -X POST http://localhost:8080/operations \
  -H "Content-Type: application/json" \
  -d '{
    "operationId": "test-operation-1",
    "amount": "100.00",
    "currency": "RUB",
    "description": "test-1"
  }'
```

### 4. Отправка провайдеру

```bash
curl -i -X POST http://localhost:8080/operations/test-operation-1/submit
```

### 5. Получение текущего состояния

```bash
curl -i http://localhost:8080/operations/test-operation-1
```

### 6. Получение истории переходов

```bash
curl -i http://localhost:8080/operations/test-operation-1/events
```
